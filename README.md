# mehrzad_ui — نمونهٔ متن‌باز داشبورد مدیریتی

رابط فارسی/RTL با ظاهر شیشه‌ای و API کوچک برای نمایش گردش‌کار مدیریت رکوردها. این مخزن در وضعیت **prototype / آزمایشی** است؛ محصول کامل مدیریت VPN نیست و رکوردهایش کانفیگ قابل اتصال تولید نمی‌کنند.

## وضعیت واقعی امکانات
- رابط: ورود، داشبورد آماری از API، فهرست/ایجاد/حذف رکوردها، طراحی واکنش‌گرا.
- API: Python استاندارد، SQLite، هش رمز PBKDF2، نشست کوکی HttpOnly و SameSite Strict (ذخیرهٔ نشست فقط حافظه‌ای)، اعتبارسنجی پایه.
- نام‌های VLESS، VMess، Trojan، Shadowsocks، WireGuard و OpenVPN صرفاً فیلد متنی/برچسب هستند. UUID هم credential عملیاتی نیست.
- پیاده‌سازی نشده: نصب/پیکربندی هسته‌های VPN، ساخت کانفیگ و QR واقعی، ترافیک و سهمیهٔ اعمال‌شده، محدودیت سرعت/انقضا، چندسروری، مدیریت نماینده/چند مدیر، TLS/reverse proxy، پشتیبان‌گیری و مهاجرت نسخه.

## اجرا برای توسعه (Python 3.10+)
```sh
python3 -m unittest discover -s tests -v
python3 app.py --setup-admin admin 'یک-گذرواژه-تصادفی-بلند-حداقل-۱۴-کاراکتری'
python3 app.py --host 127.0.0.1 --port 8080
```
مرورگر را روی `http://127.0.0.1:8080` باز کنید. مسیر DB پیش‌فرض `data/mehrzad.sqlite3` است؛ با `MEHRZAD_DB` قابل تغییر است. برنامه عمدی به loopback محدود شده و اتصال مستقیم عمومی را رد می‌کند. در وضعیت فعلی از reverse proxy اینترنتی استفاده نکنید.

## نصب فایل نمونه
روی Ubuntu 22.04 یا سیستم سازگار، آرشیو را استخراج کنید و در پوشهٔ پروژه اجرا کنید:
```sh
sudo ./install.sh
```
این فقط فایل‌ها را نصب می‌کند؛ systemd، TLS، فایروال و VPN را تنظیم نمی‌کند. فعلاً نصب‌کنندهٔ curl وجود ندارد. دستور `curl | sudo bash` تا زمان انتشار نسخهٔ tagشده، checksum/امضای قابل‌تأیید و آزمون نصب امن ارائه نمی‌شود.

## مرحلهٔ اول Xray: تولید پیکربندی VLESS + REALITY (آزمایشی)

`xray_reality.py` یک ابزار کمکی مستقل اضافه می‌کند که پیکربندی حداقلی Xray و UUID مشتری تولید می‌کند، JSON را با `xray run -test -config` اعتبارسنجی می‌کند (اگر Xray نصب نباشد با خطا متوقف می‌شود)، و فایل را با مجوز 0600 می‌نویسد. این ابزار به سرویس Xray دست نمی‌زند، سرویس را نصب/راه‌اندازی نمی‌کند، فایروال را تغییر نمی‌دهد، و هنوز به API یا رابط وصل نشده است.

برای اجرای آن باید Xray را جداگانه و از منبع رسمی نصب کنی و کلید خصوصی REALITY را با دستور متناسب با نسخهٔ Xray تولید کنی (`xray x25519`). برای آزمایش، پس از بررسی راهنمای `xray x25519` همان نسخه، مقادیر را محلی وارد کن:
```sh
python3 xray_reality.py --server-name <SNI> --dest <SNI>:443 --port 443 --private-key <PRIVATE_KEY> --output /etc/xray/config.json
```
این دستور صرفاً فایل را می‌سازد؛ مقدار `<PRIVATE_KEY>` را در چت یا GitHub قرار نده. پس از تولید، کلید عمومی متناظر، IP سرور، SNI/مقصد سازگار با REALITY، پورت باز و اعتبارسنجی نسخهٔ Xray برای لینک کلاینت باید فراهم و آزمایش شوند. دامنهٔ شخصی برای REALITY الزام فنی ندارد، اما مقصد/SNI باید درست انتخاب شود. این مرحله به‌تنهایی پنل عملیاتی یا نصب سروری محسوب نمی‌شود.

7. آزمون clean install و upgrade روی Ubuntu 22.04؛ CI و بازبینی امنیت.
8. انتشار نسخهٔ tagشده و نصب‌کنندهٔ curl که نسخه و checksum را بررسی کند.
